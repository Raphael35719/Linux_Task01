# Workflow

This directory contains the project progress tracker and Git publishing steps.

- `PROGRESS.md` — task checklist from preparation through verification.
- `GIT_BASH_GUIDE.md` — commands to initialize the repository and push it to GitHub.

Git Bash is for Git commands on your Windows computer. Run Linux task commands inside Kali Linux (for example, in the VM terminal), not in Git Bash unless you are connected to the Linux environment.
