# Scripts

This folder is reserved for optional helper scripts, such as a non-destructive environment check or a script that prints the expected directory tree.

The assignment is primarily about demonstrating Linux commands (`useradd`, `mkdir`, `touch`, `ls`, `cp`, `rm`, `chmod`, and ownership handling). Run and document the required commands yourself rather than replacing the demonstration with one opaque script.

No task-changing script is included by default, to avoid accidentally performing file operations under the wrong account.
